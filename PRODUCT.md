# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Confirmed: React and a local Python HTTP backend. No LLM dependencies. Browser and backend run on the same origin after building.

## Users
The project owner conducts authorized defensive cybersecurity coursework against owned fixture applications and owned or authorized repositories.

## Product Purpose
VibeShield makes deterministic static and dynamic scanner findings understandable, exposes scan completeness, and exports evidence-based reports.

## Operating Context
Local capstone workspace. Submit a website URL/IP or GitHub repository, follow actual scanner stages, review candidates, and download reports. The current Python scanners and deliberately vulnerable Flask fixture are the source of truth.

## Capabilities and Constraints
No LLM detection, classification, or scoring. Findings are candidates, never automatically confirmed exploits. Preserve the fixture and unavailable prober. Confirmed: website and IP scanning stays local-only for this phase. GitHub inputs are public HTTPS repositories; no credential collection. No invented scan history or vulnerability counts. Detailed project PDF documentation remains an authorized deliverable.

## Brand Commitments
Name: VibeShield. A polished, legible task-focused dashboard; no supplied logo or visual identity. Specific colors and layout are implementation assumptions, not user-confirmed brand preferences.

## Evidence on Hand
pipeline/scan/README.md, pipeline/scan/VERIFICATION.md, scanner code, 34 regression tests, and fixtures/idor-notes-app/app.py. Earlier dynamic smoke-test tools were in temporary storage and may no longer be installed.

## Product Principles
Explain every finding. Never equate an incomplete scan with safety. Present actual data. Keep consent and scope explicit. Preserve reproducibility and source attribution.
